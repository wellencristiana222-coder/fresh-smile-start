# Sorriso Feliz Clínica

Crie uma estrutura de site para uma clinica odontologica, onde na página principal o usuario consiga ver os beneficios de se consultar naquela clinica.

O site precisa conter :

Página Inicial;

 Quem Somos;

 Produtos ou Serviços;

 Galeria de imagens;

 Informações de contato;

 Botão para WhatsApp (simulado);

 Localização (simulada);

 Layout responsivo;

 Boa identidade visual.

Escreva os requisitos funcionais dessa página para que uma IA desenvolva
